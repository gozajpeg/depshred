# Security Policy

## Supported Versions

Only the latest major version of `depshred` receives security updates and vulnerability patches.

| Version | Supported |
| :--- | :--- |
| **2.x.x** | Yes |
| < 2.0.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability or potential threat in `depshred`, please report it responsibly:

1. **Do not create a public issue.** Public disclosure before a fix is available exposes projects that rely on the tool.
2. Submit a private advisory via **GitHub Security Advisories**:
   [https://github.com/gozajpeg/depshred/security/advisories/new](https://github.com/gozajpeg/depshred/security/advisories/new)
3. Alternatively, report the issue directly via email to the maintainer or create an issue requesting private contact.

### What to Include

Please provide:
- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- The affected version(s) and operating system.

### Response Commitment

- An initial response acknowledging receipt will be provided within **48 hours**.
- A patch and advisory timeline will be communicated as soon as the issue is confirmed and triaged.
